# @funtools/native-ui

A UI component library for React Native.

## Installation

```bash
npm install @funtools/native-ui
# or
yarn add @funtools/native-ui
# or
pnpm add @funtools/native-ui
```

**Peer dependencies:** Make sure you have `react`, `react-native`, `react-native-safe-area-context` and `@funtools/store` installed in your app.
